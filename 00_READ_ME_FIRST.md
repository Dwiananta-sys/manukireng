## 🚀 Quick Start (5 Minutes)

### 1. Open in VS Code
```
File → Open Folder → Select personsite folder
```

### 2. Install Live Server
```
Ctrl+Shift+X → Search "Live Server" → Install
```

### 3. Start Live Server
```
Right-click index.html → Open with Live Server
```

### 4. Customize
```
Edit data/data.js - Update experience & projects
Edit index.html - Update nama & deskripsi
Edit styles/main.css - Ubah warna tema
```

### 5. Deploy
```
Push ke GitHub → Connect ke Netlify/Vercel → Deploy
```
