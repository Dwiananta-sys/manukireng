## 🚀 Quick Start (5 Minutes)

### Step 1: Open in VS Code
```bash
# Buka folder "personsite" di VS Code
File → Open Folder → Select personsite folder
```

### Step 2: Install Live Server
```
1. Buka Extensions (Ctrl+Shift+X)
2. Search "Live Server"
3. Install dari Ritwick Dey
4. Reload VS Code
```

### Step 3: Start Live Server
```
1. Klik kanan pada index.html
2. Pilih "Open with Live Server"
3. Browser otomatis membuka
```

### Step 4: Customize
```
1. Edit data/data.js - Update experience & projects
2. Edit index.html - Update nama & deskripsi
3. Edit styles/main.css - Ubah warna tema
4. Changes otomatis reload di browser
```

### Step 5: Deploy
```
1. Push ke GitHub
2. Connect ke Netlify/Vercel
3. Deploy otomatis
4. Website live! 🎉
```

## 🌐 Deployment Options

### Recommended: Netlify
```
1. Push ke GitHub
2. Buka https://netlify.com
3. Click "New site from Git"
4. Connect GitHub & select repo
5. Deploy! ✅
```

### Alternative: Vercel
```
1. Push ke GitHub
2. Buka https://vercel.com
3. Click "New Project"
4. Import repository
5. Deploy! ✅
```

### Alternative: GitHub Pages
```
1. Create repo: username.github.io
2. Push files
3. Enable GitHub Pages
4. Live di username.github.io ✅
```
