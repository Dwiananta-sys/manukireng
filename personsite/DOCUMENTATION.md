## 🔧 Common Tasks

### Ubah Nama
File: `index.html`
```html
<span class="logo-text">Your Name</span>
```

### Ubah Warna
File: `styles/main.css`
```css
:root {
    --primary: #00d4ff;
    --secondary: #7c3aed;
}
```

### Ubah Experience
File: `data/data.js`
```javascript
const experienceData = [
    {
        title: "Your Job",
        company: "Company",
        // ...
    }
];
```

## 🆘 Troubleshooting

### Animasi tidak jalan
- Refresh page (Ctrl+Shift+R)
- Check console (F12)
- Pastikan animations.css ter-load

### Warna tidak berubah
- Clear cache
- Hard refresh (Ctrl+Shift+R)
- Check CSS syntax

### Data tidak muncul
- Check data.js syntax
- Pastikan data.js di-load
- Check console untuk error

### Responsive tidak bekerja
- Check viewport meta tag
- Test di different devices
- Check media queries
